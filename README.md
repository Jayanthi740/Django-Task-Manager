# Django Task Manager 🚀

A web-based Task Management System built using Python and Django. This application helps users manage their daily tasks efficiently with authentication, task tracking, and status management.

## ✨ Features

- User Registration and Login
- Secure User Authentication
- Create New Tasks
- View All Tasks
- Update Existing Tasks
- Delete Tasks
- Task Status Management
- Task Detail View
- Dashboard for Task Management
- Staff Report Management

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Bootstrap (if used)

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Jayanthi740/Django-Task-Manager.git
```

### 2. Navigate to the Project Folder

```bash
cd Django-Task-Manager
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

### 4. Activate Virtual Environment

Windows:

```bash
.venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Apply Migrations

```bash
python manage.py migrate
```

### 7. Run the Development Server

```bash
python manage.py runserver
```

Open your browser:

http://127.0.0.1:8000/
